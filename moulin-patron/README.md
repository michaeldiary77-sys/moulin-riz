# Moulin Patron

Application Expo 54 hors ligne pour définir les tarifs, consolider les journées des opérateurs et gérer les remboursements ou annulations de dettes.

## Commandes

```bash
npm install
npm start
npm run lint
npx tsc --noEmit
```

L’écran Synchronisation importe les journées des opérateurs et réexporte une journée fusionnée. L’écran Dettes permet d’ouvrir une dette active, de la rembourser ou de l’annuler.

Consultez le [`README.md`](../README.md) du dépôt pour les règles de fusion et le protocole CSV.
